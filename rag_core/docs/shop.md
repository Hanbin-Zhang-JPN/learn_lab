# SoraMart オンラインストア

SoraMart は、この RAG の動作確認用に作られた架空の生活用品店です。実在するサービスの規約ではありません。

## 返品条件

返品申請は、商品が配達された日の翌日から 30 日以内に行ってください。商品が未使用で、付属品と外箱がそろっている場合に返品できます。申請時には注文番号と返品理由が必要です。

初期不良または誤配送の場合、返送料は SoraMart が負担します。購入者都合の返品では、返送料は購入者が負担します。開封済みの衛生用品、名入れ商品、ダウンロード商品は返品できません。

## 返金

倉庫で返品商品を確認した後、通常 5 営業日以内に返金処理を開始します。交換品の在庫がない場合は、購入時の支払い方法へ返金します。

## 配送

通常配送は注文確定後 2〜4 営業日で発送します。合計 8,000 円以上の注文は通常配送料が無料です。離島や天候不良時には追加の日数がかかる場合があります。
