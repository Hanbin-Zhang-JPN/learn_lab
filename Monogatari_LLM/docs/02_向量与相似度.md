# 02｜向量与相似度：让编号有方向（25 分钟）

token id 只是通讯录号码。17 并不比 9“更像故事”。模型用 **embedding 表**把每个编号查成一列小数，这列小数就是向量。

想象三个临时坐标轴：自然、城市、安静。`森=[0.9,0.1,0.8]`，`海=[0.8,0.1,0.6]`。两根箭头方向接近，于是可以说它们相似。真实模型的 96 个轴没有预先命名，含义由训练共同塑造。

## 余弦相似度

点积把对应位置相乘再相加；余弦相似度再除以两根向量的长度：

```text
cos(a,b) = (a · b) / (|a| × |b|)
```

它比较方向，减少绝对长度影响。接近 1 表示同向，0 表示近似垂直，-1 表示反向。它是有用的测量，不是“真正的意义探测器”；数据偏见、语境与多义词仍会进入向量。

## 2013 年发生了什么

分布式表示并非 2013 年才出现，但 Word2Vec 让在大规模文本上高效学习词向量变得极具影响力。它的核心直觉可追溯到“一个词由它周围的词显露身份”。相似关系不再靠人逐项填写，而是在预测上下文的任务中长出来。

原论文：[Mikolov 等，Efficient Estimation of Word Representations in Vector Space](https://arxiv.org/abs/1301.3781)。
