# 03｜神经网络：靠误差微调参数（25 分钟）

一个最小神经元可以写成：

```text
预测 = 输入 × weight + bias
```

`weight` 与 `bias` 是参数。比较预测与答案，得到损失；计算“参数向哪边动会让损失降低”，得到梯度；向相反方向挪一点，就是梯度下降。

## 非线性为什么重要

多个纯线性层叠起来，仍可合并成一个线性层。GELU 这样的非线性函数让网络能弯曲决策边界。项目的前馈网络是：`96 → 384 → GELU → 96`。扩张让每个位置独立加工信息，再缩回主干宽度。

## 一段不平坦的历史

1958 年 Rosenblatt 的感知机展示了可学习分类器；1969 年 Minsky 与 Papert 对单层感知机局限的分析后来常被简化成“神经网络失败了”。1986 年 Rumelhart、Hinton 与 Williams 系统展示反向传播如何训练多层表示，重新点燃兴趣。历史不是单线胜利：算力、数据、算法和研究风潮缺一不可，“冬天”也不只由某一篇论文造成。

参考：[Learning representations by back-propagating errors（1986）](https://www.nature.com/articles/323533a0)。
