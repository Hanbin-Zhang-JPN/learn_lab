# 01｜分词：电脑先看见编号（25 分钟）

电脑不能直接拿“鎌倉”做矩阵乘法。第一步是规定怎样把文字切成 **token**，再给每个 token 一个整数编号。

## 为什么日文更值得先想分词

英文句子常有空格，日文却可以连续写成 `葵は鎌倉へ行った`。按“词”切，需要词典和形态分析；按子词切，需要先学习一个词表；按字符切只要承认 `葵`、`は`、`鎌`、`倉` 各是一个单位。

本项目选择字符级，不是因为它最先进，而是因为它最适合第一次打开机器：

- 好处：规则只有一句；解码直观；不下载分词器。
- 代价：序列较长；没见过的罕见汉字会成为 `<unk>`；一个 token 不等于一个词义。

四个特殊 token：`<pad>` 补齐批次，`<bos>` 表示开始，`<eos>` 表示结束，`<unk>` 接住词表外字符。

## 历史为什么从词走到子词

早期统计语言模型通常把词当单位，却会遭遇“词表爆炸”和未登录词。1994 年的 BPE 原本是压缩算法；后来被引入神经机器翻译，在词与字符之间寻找折中。今天许多大模型使用 BPE 或近亲方法。它们提高效率，却也提醒我们：token 是工程划分，不是语言天然存在的原子。

可追溯阅读：[Sennrich 等，Neural Machine Translation of Rare Words with Subword Units（2015）](https://arxiv.org/abs/1508.07909)。
