# 06｜训练、生成与分享（20 分钟阅读 + 训练时间）

## 先看一条数据

```bash
python lessons/06_data.py
```

`data.py` 从姓名、地点以及四套可见的句子部件中组合 8,000 条故事。恋愛、文芸、ユーモア、恐怖各占四分之一。固定随机种子意味着同一版本每次得到相同数据，便于复现。

每条训练文本都有一行 `作風:文芸`（或另外三种作风）。模型并没有一个写死的“恐怖开关”；它在许多样本中发现作风标签与后文用词同时出现，才逐渐学会把标签当成条件。网页下拉框最终写入的正是这一行。

它比下载网络小说更透明，也避开版权语料。但要诚实评价：模型会学习这些模板的文风，不能把结果当成“真正理解日本文学”。增加更多高质量、获得许可的原创句子，通常比盲目增加层数更有意义。

## 训练循环

```bash
python -m monogatari_llm.train
```

终端会显示设备、词表、参数量、loss 和用时。默认上限 3,000 步或 85 分钟。验证 loss 是模型在没有参与参数更新的一小份数据上的错误；保存验证结果最好的版本，能减少“只记住训练集”的风险。

按 `Control + C` 可以提前停。检查点在 `artifacts/monogatari.pt`，含权重、模型配置和词表。

## 生成不是检索

```bash
python -m monogatari_llm.generate --name 葵 --place 鎌倉 --style 文芸
```

模型每次得到 logits，经 temperature 调节，再只保留 top-k 候选并抽样。temperature 较低更稳、更重复；较高更多变，也更容易失控。试试 `--temperature 0.65` 与 `1.05`。

## 浏览器为什么也能跑

`export_web.py` 不会转换成神秘格式。它把每个 float32 张量依次写进 `model.bin`，并在 JSON 中记录名称、形状和字节偏移。网页的 `lib/browser-model.ts` 用普通 TypeScript 重做 embedding、LayerNorm、线性层、注意力和采样。

```bash
python -m monogatari_llm.export_web
npm run dev
```

## URL 的两种含义

临时 URL 用 Cloudflare Tunnel 把朋友的浏览器连到你电脑上的网页服务器。你的 Mac 必须保持开机。固定 URL 则把网页与约 2MB 权重放到静态托管；推理仍在朋友浏览器，不需要 GPU 服务器。

分享前至少固定一组姓名和地点，把四种作风各试一次；这样才看得出模型是否真的利用了条件。告诉朋友这是一个小型教学实验，不要用真人隐私做公开测试。

完成标志：你能从数据文件一路指到浏览器中的故事。三小时主线到此结束。
