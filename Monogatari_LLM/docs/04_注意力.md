# 04｜注意力：当前字符该看前面的谁（35 分钟）

生成到某个位置时，并非所有旧字符同样重要。看到 `場所:鎌倉` 后，模型写地点时应更关注“鎌倉”；选择阴森还是轻快的词时，则应回看 `作風:恐怖` 或 `作風:ユーモア`。注意力把这种“相关程度”变成可学习的权重。

## Q、K、V 的朴素比喻

- Query：当前位置正在找什么？
- Key：每个旧位置可以用什么被找到？
- Value：若找到它，要取回什么内容？

`Q × Kᵀ` 得到匹配分数，除以 `sqrt(d)` 避免维度变大时数值过激，softmax 把分数变为总和为 1 的权重，最后加权混合 V：

```text
Attention(Q,K,V) = softmax(QKᵀ / √d) V
```

## 因果遮罩

训练时整段答案都在一个张量里。若位置 5 可以看位置 6，就等于考试偷看右边答案。下三角遮罩只允许它看自己与左侧。`model.py` 的 `causal_mask` 就是这条规则。

## 历史转折

循环网络曾按时间一步步压缩序列，长距离信息难保留。2014 年前后的神经机器翻译注意力让解码器在每一步重新对齐输入位置。2017 年 Transformer 更激进：不再把循环当主骨架，主要依靠自注意力和前馈网络，并可并行训练。

原始入口：[Bahdanau 等，Neural Machine Translation by Jointly Learning to Align and Translate](https://arxiv.org/abs/1409.0473)；[Vaswani 等，Attention Is All You Need](https://arxiv.org/abs/1706.03762)。

评论：论文标题极具传播力，但真实 Transformer 并非“只有注意力”——残差、归一化、前馈层、位置表示和优化方法同样关键。
