# 00｜从这里开始（15 分钟）

这一项目只追一条问题：**电脑怎样从“葵、鎌倉、文芸”走到一段日文故事？**

先把训练想成学填空。给模型看：

```text
名前:葵
場所:鎌倉
作風:文芸
物語:鎌倉で、葵は古い鍵を……
```

遮住最后一个字符，让它猜；公布答案，记录猜错多少；把内部数字轻轻调一下；再猜。几千次之后，它不是把“故事规则”存成一句人能读的定律，而是把很多细小倾向分散进约 40 万个参数。

## 三个名词先够用

- **模型**：一个有许多可调整数字的计算过程。
- **训练**：用例子反复调整这些数字，使错误变小。
- **推理**：停止调整，只用已经学到的数字生成结果。

本项目的训练数据也在本机生成。你会看到句子部件，看到它们怎样组合，所以不会遇到“神秘下载了几十 GB 文本”的黑箱。但请记住：透明不等于自然。合成数据会让模型写得规整，也会限制它的变化。

## 先运行

```bash
python lessons/00_check.py
```

M3 的 GPU 在 PyTorch 里叫 **MPS**，不是 CUDA。若显示 `MPS 可用: True`，训练会交给 Apple GPU；否则代码仍可用 CPU，只是会慢。官方入口是 [PyTorch macOS 安装说明](https://docs.pytorch.org/get-started/locally/) 与 [MPS 后端说明](https://docs.pytorch.org/docs/stable/notes/mps.html)。

```text

```
