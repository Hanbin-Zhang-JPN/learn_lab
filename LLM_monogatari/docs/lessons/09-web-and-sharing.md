# 第 9 课：从 localhost 到一个 URL

网页有三层，全部可以在仓库中打开：

```text
web/index.html + styles.css + app.js
            │ POST /api/story
            ▼
src/llm_monogatari/web.py
            │ prompt + adapter
            ▼
本机 MLX 模型
```

浏览器把人名和地名作为 JSON 发给 Python。服务器校验长度与日文字符，拼固定 prompt，串行调用模型，再把故事作为 JSON 返回。`textContent` 显示故事，避免把模型输出当 HTML 执行。

## 本地运行

训练完成后：

```bash
make web
```

访问 `http://127.0.0.1:8000`。`127.0.0.1` 指当前电脑，外界不能直接访问。服务器默认查找 `adapters/LLM_monogatari-lora`；若不存在会拒绝生成，不会悄悄换成基座。

不加载模型预览页面：

```bash
make demo
```

## 临时分享

保持网页终端运行，再开一个终端：

```bash
make share
```

Cloudflare Quick Tunnel 会把随机的 `trycloudflare.com` 地址转发到本机 8000 端口。它适合测试：地址随机、终端关闭即失效，也没有本项目控制的账号登录。微信可能对新域名给出安全提示；不要尝试绕过平台安全提示。

必须同时满足：

- Mac 保持唤醒、联网；
- 两个终端都在运行；
- 模型已经下载；
- 分享者接受输入会经过 Cloudflare 网络并到达这台 Mac。

Quick Tunnel 是外部黑盒边界之一。完全不依赖外部中继，就无法让互联网中的朋友穿过家庭路由与防火墙稳定访问本机。若以后需要固定域名和长期在线，应使用有认证、配额、日志治理和持续运行主机的正式部署；这已经超出本学习项目的目标。

## 已做和没做的防护

已做：输入只允许 1–20 个日文字符；请求体上限 2KB；每来源每分钟最多 6 次；同一时刻只执行一次生成；页面不执行模型输出；不向公网返回内部错误路径。

没做：账号登录、持久配额、内容审核、HTTPS 证书控制、可靠审计、服务等级保证。限速也只是轻量措施，不能抵抗认真攻击。因此只把 URL 给少量认识的人，发现异常立即在两个终端按 `Control + C`。

## 微信分享注意

复制 URL 前先用手机移动网络打开一次。告诉朋友这是临时实验、输入不要含私人信息、生成文本可能不自然或不合适。朋友圈公开范围比私聊大很多；第一次只在私聊中测试。

## 完成标准

能解释 localhost、服务器和隧道三者区别；能从浏览器开发者工具看见 `/api/story` 请求；知道怎样立即让公网 URL 失效。
