# 第 10 课：把今天放回历史中

LLM 常被叙述成少数突破的连续胜利。更准确的图景是多条线索长期汇合：统计语言学、神经网络、表示学习、硬件、数据基础设施、开源软件、基准与商业投资。

## 一条压缩时间线

| 年代 | 代表节点 | 留下的问题 |
|---|---|---|
| 1913–1948 | Markov 链、Shannon 信息论 | 怎样量化序列的不确定性？ |
| 1943–1969 | 逻辑神经元、感知机及其局限 | 什么能学习，什么无法线性分开？ |
| 1980s–1990s | 反向传播、分布式表示、RNN/LSTM | 怎样把误差传到内部表示并保留上下文？ |
| 2000s | 神经概率语言模型、统计机器翻译 | 怎样共享稀有词的统计强度？ |
| 2013–2017 | word2vec、seq2seq、attention、Transformer | 怎样高效学习与汇聚长序列信息？ |
| 2018–2020 | 大规模预训练、BERT、GPT 系列 | 一个预训练模型能否迁移到许多任务？ |
| 2021–2023 | 指令微调、RLHF、LoRA、QLoRA | 怎样让模型可用、可控并降低适配成本？ |
| 近年 | 多模态、长上下文、工具调用、本地推理 | 能力、成本、治理和可验证性怎样平衡？ |

年份不是发明唯一归属。许多“新”方法有更早思想来源；论文发布、规模化验证和社会影响也不是同一件事。

## 五个评述角度

### 1. 基准不等于使用场景

排行榜把复杂能力压成一个分数。测试集可能被训练数据污染，提示格式也会影响结果。我们的小故事任务因此使用固定格式、未见组合与人工评分，同时保留失败案例。

### 2. 规模改变能力，也改变谁能研究

大模型带来广泛能力，但预训练的算力、数据和工程成本使完整复现集中于少数机构。本项目选择 0.6B 与 LoRA，是在个人硬件上保留实验自主性的折中，不是声称小模型等价于前沿模型。

### 3. “公开权重”不等于“完全开放”

权重可下载，不代表训练数据、过滤流程、日志和计算配方全部可复现；开源代码也不让六亿参数变得逐项可读。要分别谈代码、权重、数据、许可和治理。

### 4. 流畅不等于真实或理解

下一个 token 预测能产生连贯行为，但输出的语气不会自动附带证据。对“理解”的哲学争论可以继续，同时工程上应检查更具体的可靠性、迁移、因果干预和失败条件。

### 5. 数据包含劳动与权利

语料不是自然掉进硬盘的。作者、标注者、审核者和平台用户都参与其中。数据许可、隐私、语言覆盖与内容伤害不应等到发布时才补想。本项目不用抓取小说，要求逐篇审自己的小数据，就是把这个问题放在训练之前。

## 最后的练习

写一页实验札记，回答：

1. 哪一个结果支持了你的假设？
2. 哪一个失败最有信息量？
3. 当前证据不能支持什么结论？
4. 如果只能再收集 20 篇数据，你会补哪种缺口？
5. 哪一项依赖仍然是你无法审计的？

能诚实回答第 3 和第 5 题，比做出一篇偶然漂亮的故事更接近真正理解模型。
