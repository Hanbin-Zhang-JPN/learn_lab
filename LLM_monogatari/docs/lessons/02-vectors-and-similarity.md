# 第 2 课：向量、位置与相似度

token id 只是编号。`7` 比 `3` 大，不表示第 7 个词比第 3 个词“更多”。模型需要把离散编号映射成可计算的向量。

## 从 one-hot 开始

词表是 `[猫, 犬, 鳥]` 时：

```text
猫 = [1, 0, 0]
犬 = [0, 1, 0]
鳥 = [0, 0, 1]
```

这叫 one-hot。每个词彼此正交，无法表达猫与犬比猫与轮船更接近。词袋表示把句子中各词的次数填入同一空间。它能比较共同词，但丢掉顺序：`猫が犬を追う` 与 `犬が猫を追う` 的词袋相同。

## 点积与余弦

点积把对应位置相乘后求和：

```text
[1, 2] · [3, 4] = 1×3 + 2×4 = 11
```

它同时受方向和长度影响。余弦相似度再除以两个向量的长度，只比较夹角：

```text
cos(a,b) = (a·b) / (|a||b|)
```

同向接近 1，垂直接近 0，反向接近 -1。运行：

```bash
make lesson N=2
```

再在纸上手算 `[1,1]` 与 `[1,0]`，应得到约 `0.707`。

## embedding 是可学习的查表

神经语言模型准备一个“词表大小 × 隐藏维度”的矩阵。token id 选择其中一行，这一行就是 embedding。训练改变这些数字，使对预测下一个 token 有用的模式逐渐靠近或分开。

“国王 - 男人 + 女人 ≈ 女王”的例子让词向量广为人知，但不要把漂亮的类比当作一般定律。结果依赖语料、任务、维度、训练目标与筛选方式。现代 Transformer 还会让同一个 token 在不同上下文得到不同的隐藏向量；静态词向量只是入口。

## 历史坐标

- 1950 年代，分布式语言观提出“词由它出现的环境体现”；
- 1990 年，Latent Semantic Analysis 用矩阵分解寻找文档与词的潜在结构；
- 2003 年，神经概率语言模型共同学习词向量和下一个词概率；
- 2013 年，word2vec 用高效预测任务普及大规模词嵌入；
- 2018 年前后，ELMo、BERT 等上下文化表示让“一个词一个固定向量”不再是默认。

这种历史也提醒我们：向量中的规律来自语料。社会偏见、体裁偏差和数据缺口同样会被编码。余弦给出的是某个表示空间里的几何关系，不是伦理判断或客观真理。
