# 第 3 课：神经网络究竟学了什么

一个最小神经元做三件事：输入乘权重、加偏置、通过非线性函数。

```text
y = tanh(w₁x₁ + w₂x₂ + b)
```

权重决定各输入的影响，偏置移动阈值，`tanh` 让多个线性层叠加后不再等价于单个线性变换。

## 训练的五步循环

1. 前向传播：用当前参数算预测；
2. 损失函数：把预测与目标的差异变成一个数；
3. 反向传播：用链式法则求每个参数对损失的影响；
4. 参数更新：沿降低损失的方向走一小步；
5. 在新样本上检查，而不是只记住训练题。

梯度不是“应该把参数改成什么”，而是“参数增加一点时，损失会怎样变化”的局部斜率。学习率决定每次沿斜率走多远。

打开 `src/llm_monogatari/autograd.py`。`Value` 保存数值、梯度、父节点和局部反向函数。`backward()` 先按依赖关系排序，再从输出倒着传播。运行：

```bash
make lesson N=3
```

例子让一个 `tanh` 神经元学习 AND。观察 loss 下降，再把学习率从 `0.05` 改成 `5.0`。如果训练震荡或发散，这不是电脑坏了，而是步子太大。

## 历史坐标

- 1943：McCulloch 与 Pitts 用逻辑神经元讨论神经活动；
- 1958：Rosenblatt 的感知机把学习规则与硬件实验结合；
- 1969：对单层感知机局限的讨论，尤其 XOR，促成一段研究降温；
- 1986：Rumelhart、Hinton、Williams 系统展示反向传播学习内部表示；
- 1990s–2000s：卷积网络、LSTM 等在特定任务积累成果；
- 2010s：更大数据、GPU、初始化与优化改进共同推动深度学习扩张。

“神经网络因为模仿大脑才成功”是过度简化。名称提供了历史灵感，现代网络的训练目标、精确反向传播和数据规模与生物脑相差很远。另一种过度简化是把发展只归因于某个算法：算力、数据、软件、基准、资金和组织也改变了哪些想法能被试验。

## 过拟合

训练 loss 低只说明模型适合看过的数据。若验证 loss 上升，常表示模型开始记住训练集细节。训练集用于更新参数；验证集用于选设置或停止时间；测试集只在最后估计一次。反复看测试结果再调参，测试集也会变成训练信息。
