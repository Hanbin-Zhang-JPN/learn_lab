# 第 4 课：预测下一个 token

自回归语言模型把联合概率拆成一连串条件概率：

```text
P(葵, は, 海, へ) = P(葵) × P(は|葵) × P(海|葵は) × P(へ|葵は海)
```

训练时，输入真实前文，要求模型提高真实下一个 token 的概率。生成时，没有后续答案可看，于是把刚生成的 token 接回输入，循环继续。

## 先看 bigram

bigram 假设下一个字符只依赖上一个字符。它统计 `葵→は`、`は→海` 出现几次，归一化成概率。`src/llm_monogatari/bigram.py` 就是完整模型。

```bash
make lesson N=4
```

它可能产生局部像日文、整体却混乱的文字。这正好展示“局部条件概率”与“长距离结构”之间的差距。平滑项给没见过的转移一点非零概率，否则测试集里一个新组合就会让整句概率归零。

## logits、softmax 与交叉熵

网络最后输出一组任意实数 logits。softmax 把它们变成和为 1 的概率。为数值稳定，要先减去最大 logit；这不会改变概率比例，却能避免 `exp(1000)` 溢出。

真实 token 概率为 `p` 时，交叉熵损失是 `-log(p)`。预测 0.9，损失约 0.105；预测 0.01，损失约 4.605。困惑度是平均交叉熵的指数，可粗略理解为模型在每步面对多少个同样可能的选择，但只能在相同 tokenizer、数据与计算方式下比较。

## 采样不等于知识

- temperature 小于 1：放大概率差异，输出更稳定；
- temperature 大于 1：压平分布，输出更多样也更易失控；
- top-k：只从概率最高的 k 个候选抽；
- top-p：取累计概率达到 p 的最小候选集合。

这些方法改变“怎样从分布选 token”，不改变模型参数，也不会补充事实。一个流畅故事仍可能有事实错误。

## 历史坐标

1913 年，Markov 用《叶甫盖尼·奥涅金》的元音/辅音序列研究相关性。1948 年，Shannon 用熵建立信息论，也展示按字符统计生成近似英文。此后 n-gram 长期是语言建模主力。2003 年神经概率语言模型用分布式表示缓解离散计数稀疏；RNN、LSTM 再把可用上下文拉长；Transformer 则改变了信息汇聚方式。

不要把历史描述成“统计方法失败，神经网络成功”。现代模型仍然是概率模型，交叉熵、采样与评测中的许多概念延续自统计语言建模。

## 完成标准

用自己的话区分训练时的真实前文和生成时的自回馈；解释 temperature 为什么不属于微调；说明困惑度为何不能跨 tokenizer 随意比较。
