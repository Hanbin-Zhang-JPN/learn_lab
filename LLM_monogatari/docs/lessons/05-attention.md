# 第 5 课：注意力怎样取回相关信息

句子中每个位置都产生三个向量：Query、Key、Value。可以把它们暂时想成：

- Query：我现在想找什么；
- Key：我这里可以用什么线索被找到；
- Value：如果找到我，实际取走什么信息。

类比只是入口。三者本质上都是由隐藏向量乘不同权重矩阵得到的数值。

## 公式拆成四步

```text
Attention(Q,K,V) = softmax(QKᵀ / √d) V
```

1. 每个 Query 与所有 Key 点积，得到匹配分数；
2. 除以 `√d`，防止维度大时点积幅度过大、softmax 过早饱和；
3. softmax 把分数变成权重；
4. 对 Value 做加权求和。

运行：

```bash
make lesson N=5
```

输出是注意力矩阵。第 i 行表示第 i 个 token 从各位置取了多少信息。因果语言模型不能在预测当前位置时看见未来，所以矩阵右上角被遮成 0。完成 `exercises/03_causal_mask.py`，关掉遮罩观察差别。

## 自注意力与多头

Q、K、V 都由同一序列产生时叫 self-attention。多头注意力并不是把同一答案复制多次；每个头有不同投影参数，可能形成不同关系，再把各头输出拼接。但“某一头就是语法头”这类解释通常不稳定：单个可视化是线索，不是完整因果解释。

计算一个长度为 n 的完整注意力矩阵，朴素成本随 `n²` 增长。上下文变长时，内存和时间因此迅速增加。后来大量工作研究稀疏、线性、滑动窗口和高效 kernel；它们通常在精确性、可实现性和硬件效率之间交换。

## 历史坐标

2014 年，Bahdanau、Cho、Bengio 为神经机器翻译引入可学习对齐，缓解编码器把整句压进单一固定向量的瓶颈。2017 年 Transformer 用 self-attention 取代主要的循环结构，使序列位置能并行计算，并依靠位置表示保留顺序信息。

“Attention Is All You Need”是论文标题，不表示模型真的只剩注意力。Transformer 还依赖 embedding、前馈网络、残差连接、归一化、位置机制、训练目标、优化器与大量数据。
