# 透明度账本

“开源”与“可理解”不是同一个开关。这里逐层写明哪些是我们能完整检查的，哪些只是可查源代码，哪些仍依赖外部系统。

| 部分 | 可见程度 | 本仓库怎样处理 |
|---|---|---|
| 字符分词、BPE | 全部实现可读 | 纯 Python，算法和测试都在 `src/llm_monogatari` |
| 向量、余弦、softmax | 全部实现可读 | 不调用 NumPy；可手算对照 |
| 自动求导 | 全部实现可读 | 标量图与链式法则完整保留 |
| attention / 小 Transformer | 全部实现可读 | 只实现教学所需前向传播，明确省略项 |
| 故事训练数据 | 每篇可读 | 36 张起跑卡；不抓网络小说；脚本检查格式 |
| Python 标准库 | 可查源代码，非本仓库实现 | 文件、HTTP、JSON 等基础设施 |
| MLX / MLX-LM | 开源、版本固定 | Apple Silicon 的矩阵计算、量化、LoRA 与推理 |
| Qwen3 架构与许可 | 模型卡和代码公开 | Apache-2.0；配置可检查 |
| Qwen3 预训练权重 | 可下载但不可逐参数解释 | 这是最大黑盒；本项目不宣称能完整审计预训练数据 |
| Hugging Face 下载 | 外部分发服务 | 只在首次获取模型/文件时需要；缓存后本地推理 |
| Cloudflare Quick Tunnel | 外部网络服务 | 完全可选，只用于临时分享；本地学习不依赖 |
| 浏览器、macOS、Metal | 系统层 | 由 Apple 与浏览器供应方维护，不在仓库内 |

## 教学实现故意省略了什么

- BPE 没有 byte fallback、正则预分词和特殊 token 管理；
- 自动求导只处理标量，不做张量广播；
- TinyDecoder 只有单头、单层、固定正弦以外的简单位置表，且不训练；
- 网页服务器不具备生产级账号、审核、监控与持久任务队列；
- 数据规模不能支撑文学质量或安全性的强结论。

省略不是缺陷清单，而是学习边界。每个省略项都可以成为后续实验，但不应在理解前一次性补齐。

## 怎样核对外部依赖

```bash
.venv/bin/python -m pip show mlx mlx-lm
.venv/bin/python -m pip freeze
git diff
```

模型缓存通常在 Hugging Face 的本地缓存目录，本项目不移动也不提交它。不要用来源不明的 pickle 模型；这里使用 `safetensors` 权重。即便格式避免任意 Python 反序列化，也仍需信任下载来源和模型内容。
