# 模型说明卡

## 名称与目的

工作名：`LLM_monogatari-lora`。

目标：接收一个日文人名和一个日文地名，生成约 120–260 日文字符的温和短故事。用途是个人学习、演示与小范围娱乐。

不适用：事实问答、儿童无人监督使用、心理/医疗/法律建议、真实人物传记、自动发布大量内容、面向公众的无审核服务。

## 组成

- 基座：`mlx-community/Qwen3-0.6B-4bit`（Qwen3-0.6B 的 MLX 4-bit 转换）；
- 适配：LoRA，最后 8 层的 attention q/v 投影，rank 8；
- 框架：MLX-LM 0.31.3；
- 数据：见 `DATA_CARD.md`；
- 提示：见 `src/llm_monogatari/story_data.py`，不是隐藏系统提示。

adapter 不包含完整基座，无法独立运行。发布 adapter 时应同时说明兼容的精确基座名称、MLX-LM 版本、配置与基座许可。

## 已知限制

- 0.6B 容量小，日文细节、长程一致性与世界知识有限；
- 起跑数据只有 36 篇，极易重复开头、意象和句式；
- 人名/地名字符校验降低提示注入面，但不是内容安全系统；
- 模型可能编造地理事实、输出不自然日文或遗漏输入；
- 温和训练数据不能保证所有输入下都温和；
- 量化与采样使输出和非量化基座不同；
- 公网分享没有账号体系，不适合长期开放。
